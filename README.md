1st Shader:

For the First shader I implemented a modified bump map shader. I have modified it to multiple in a gradient to the stone texture. This enhances the stone element as real stone would stick out in places and not just be a flat texture. I also included the gradient as the stone would be wet where the waves crash into it, therefore by making a dark to light graident it mimics this affect.

2nd Shader:
For my second shader I used a rim light shader and modifed it to change colours. I feel like this enhances the original game as it looks more like its exploding and fire is coming off of it rather than just the original static object.

3rd Shader:
As seen in "FInal Presentation of Scene" Image waves are using the moving water shader, I feel like this fits the dark gloomy scene and also be used to infer a storm is approaching. 

$th shader:
I included the transparency shader for adding the trees, this is too give them a more realistic look while also not using up as much data, I think these kinds of trees would likely to be in this environment and it adds more detail to what trees are there unlike the orignal 2D art.

6th shader:
I included the metal shader on top of various items in the scene but with different textures. The platform is brighter metal with lots of shine because it is closer to the explosion effects therefore would be brighter. Than for the other metal box(gun?) I made the metal darker as in the scene there is no close lighting or reason for it to be brighter, creating some sense of lighting in the scene.
